**ENG**
# Launch

Launch in the web folder via: `npm run dev` 
Launch in the back folder (in the **vanv\Scripts** folder) via: `.\activate` (full: `.\venv\Scripts\activate` )
to exit the virtual environment: `deactivate` 


# Key for the Back
Rename **key.env.example** to **key.env** and insert your key without quotes or other characters in the field: **'SECRET_KEY'**





**RU**
# Launch

Запуск в папке веба через: `npm run dev` 
Запуск в папке бэка (в папке **vanv\Scripts**) через: `.\activate`  (полный `.\venv\Scripts\activate` )
чтобы выйти из виртуального окружения: `deactivate` 


# Ключ для Бэка
Переименовать **key.env.example** в **key.env** и вставить в нем свой ключ без кавычек и прочих знаков, в поле: **'SECRET_KEY'**
